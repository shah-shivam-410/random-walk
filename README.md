# Touch Grass: Random Walk

A tiny browser app for turning spare time into a nearby walk. Choose 5, 10, or 20 minutes, share your location with the browser, get an outdoor mission generated by GitHub Copilot, and open walking directions to a nearby waypoint.

## Requirements

- Node.js 20.19+ or 22.12+
- GitHub Copilot CLI installed and signed in with an eligible Copilot subscription

The mission is generated through the GitHub Copilot SDK on the local Node.js server. The browser never receives Copilot credentials. Your coordinates are used only in the browser to calculate a waypoint and make the Google Maps link; they are not sent to Copilot or stored.

## Run locally

```sh
npm ci
npm start
```

In Windows PowerShell, use `npm.cmd ci` and `npm.cmd start` if script execution policy blocks `npm`.

Open [http://localhost:3000](http://localhost:3000) and allow location access. Browser geolocation is available on localhost and secure (HTTPS) pages. Select a duration and press **Find my little adventure**.

If mission generation fails, check that the Copilot CLI is installed, signed in, and available to the SDK, then try again. The app reports the failure instead of showing a canned mission as AI-generated.

## Checks

```sh
npm test
```

The waypoint is an approximate destination in a random direction, sized to about half the selected time at a leisurely walking pace. Google Maps calculates the actual route; it may differ from the estimated duration.
